# Srihari's teiknical

once in a Codespace, running the make commands will install dependencies, build the db, and start everything up, including a uvicorn web server and a Node.js process (stack used is Python + React w/ Typescript :) )

you can access the website by Cmd/ctrl-clicking the localhost link that appears in the terminal after the third make command completes

or, the dashboard is also publicly deployed and accessible here: https://teiknical.onrender.com/. it's on a free-tier so it might cold start
