# Srihari's teiknical

once in a Codespace, running the make commands will install dependencies, build the db, and start everything up, including a uvicorn web server and a Node.js process (stack used is Python + React w/ Typescript :) )

you can access the website by Cmd/ctrl-clicking the localhost link that appears in the terminal after the third make command completes. if you're not signed in on github, make sure to make the 3000 port public first (click on Ports next to Terminal, right click Private in the Visibility column for port 3000, and change it to public)

or, the dashboard is also publicly deployed and accessible here: https://teiknical.onrender.com/
